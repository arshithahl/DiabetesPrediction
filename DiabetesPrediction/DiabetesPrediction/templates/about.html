About This Project

This Diabetes Prediction System is an advanced machine learning application designed to help users assess their risk of developing diabetes. Our system analyzes various health parameters to provide accurate predictions and early warnings.

How It Works

Our system uses a trained machine learning model that analyzes several key health indicators:

  • Pregnancies - Number of times pregnant
  • Glucose - Plasma glucose concentration
  • Blood Pressure - Diastolic blood pressure
  • Skin Thickness - Triceps skin fold thickness
  • Insulin - 2-Hour serum insulin
  • BMI - Body mass index
  • Diabetes Pedigree Function - Family history
  • Age - Age in years

Technology

Built with Django framework and powered by machine learning algorithms, this system provides a user-friendly interface for diabetes risk assessment. The model has been trained on extensive medical datasets to ensure accuracy and reliability.
